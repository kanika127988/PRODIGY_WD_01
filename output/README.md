# 🚀 Prodigy InfoTech Web Development Internship - Task 01

## 📌 Project Overview
This repository contains **Task 01** of the Web Development Internship at **Prodigy InfoTech**. The objective of this task was to design and build a modern, fully **Responsive Landing Page** ("NeonPulse") equipped with interactive navigation elements, a smooth scroll-triggered glassmorphism effect, and a mobile-friendly layout.

---

## ✨ Key Features & Functionality
* **Dynamic Scroll-Triggered Navigation:** The navigation bar changes from transparent to a dark frosted-glass style (`backdrop-filter: blur`) automatically when the user scrolls down the page.
* **Responsive Mobile Menu:** Includes an interactive hamburger menu toggle that seamlessly adapts for mobile devices and tablets.
* **Modern Tech Aesthetic:** Styled using a sleek dark-mode palette complemented by glowing neon cyan accents and clean typography.
* **Cross-Browser Compatibility:** Built using standard web standards to ensure smooth performance across various modern browsers.

---

## 🛠️ Technologies Used
* **HTML5:** For structured semantic markup and content organization.
* **CSS3:** For styling, Flexbox layouts, CSS variables, and media queries.
* **JavaScript (ES6+):** For DOM manipulation, scroll event listeners, and interactive mobile menu toggling.
* **FontAwesome:** For modern vector icons.
* **Google Fonts**: For typography (`Plus Jakarta Sans`).
